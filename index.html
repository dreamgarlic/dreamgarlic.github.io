이 문서는 일반 플레이어 4명과 외부 고객 1명으로 진행하는 게임의 독립 규칙서다. 다른 대화, 설계 문서, 코드 없이 이 문서의 수치와 절차만으로 진행한다. 일부 부동산의 보통주를 무료로 배분한 상태에서 시작하며, 세 특수 코너에서 묶음 경매·사회보장기금·다음 차례 목적지 선택을 처리한다. 외부 고객은 미분양 부동산의 경매를 열지 않는다. 부동산은 출발점부터 시계방향으로 첫 변 AAAAAA, 둘째 변 BBBBBB, 셋째 변 CCCCCC, 넷째 변 DDDDDD를 배치하며, 증축은 횟수·규모 상한 없이 누적 투자액에 따른 체감 성장 함수를 적용한다. 본문에 명시된 운영 세칙과 수치는 모두 이 판에서 적용하는 확정 규칙이다.

1 목표와 종료 조건

  • 현금과 부동산 지분을 운용해 순자산을 늘린다.
  • 한 플레이어가 출발점 정산에서 연속 두 번 경고를 받으면 즉시 전체 게임이 끝난다.
  • 그 플레이어는 순자산과 관계없이 4위다.
  • 나머지 세 명은 종료 시점의 현금 + 지분 평가액 - 개인 부채 원금으로 순위를 정한다.
  • 종료 후 남은 사람의 추가 차례나 탈락자 자산 매각은 없다.
  • 순자산이 같으면 공동 순위다. 예를 들어 공동 1위 두 명, 3위 한 명, 탈락자 4위로 처리한다.
  • 턴 수나 라운드 수에 따른 자동 종료는 없다. 별도의 무승부·시간초과 승패 규칙도 없다.

2.2 금액과 기록

  • 지분 수량은 0 이상의 정수다.
  • 배당과 이자는 소수 또는 분수 금액을 허용한다. 정확한 유리수 연산을 기준으로 하며, 소수 둘째 자리 반올림은 화면 표시용으로만 사용한다.
  • 현금·부채·의결권·입찰 자격·승패는 표시 반올림 전 값으로 판정한다. 단, 제3.1절의 통행료 함수 정수화는 게임 규칙으로 적용하며, 정수화한 T가 실제 청구·배당·평가에 사용하는 금액이다.
  • 현금과 부채는 음수가 될 수 없다. 통행료와 의무 기금 납부의 현금 부족분은 각각 제8절과 제3.4절의 대납으로 처리한다.
  • 주식 발행 입찰가격은 양의 정수이자 10의 배수다. 제3.3절의 묶음 경매 가격과 최저가는 0 또는 음수를 포함한 10의 정수배를 허용한다. 기존 지분의 일반 매매 가격에는 이 단위를 적용하지 않는다.
  • 모든 현금·부채·지분·경고·부동산 누적 투자액과 최초 확정 보통주 수·자유이동권·기금 잔액과 납부자는 공개 정보다. 경매의 묶음 구성과 최저가도 공개하며, 입찰표는 일괄 공개 전까지 비공개다.

  • 나머지 16곳은 누구도 지분을 갖지 않는다. 첫 일반 플레이어 방문 때 제7절의 5주 최초 공급을 진행한다. 초기 분양 8곳의 6주와 구별한다.

2.4 시작 절차

  1. 실제 사람을 시계방향 좌석 P1~P4에 배정한다. 미리 정한 자리가 없으면 참가자 등록 순서다. 배분 결과를 보고 좌석을 바꾸지 않는다.
  2. A·B·C·D형 각각에 제2.3절의 독립 추첨을 적용하여 초기 8곳의 지분을 기록한다.
  3. 각자 12주, 네 유형 각 3주, 현금 1000, 부채 0, 경고 0, 자유이동권 없음을 확인한다.
  4. 초기 8곳은 N₀=N=6과 U=0, 나머지 16곳은 N₀=N=U=0이다. 모든 부동산은 I=x=0이다. 사회보장기금은 0, 납부자는 없음이다.
  5. 모든 말을 0번에 놓고 라운드 번호를 1, 선플레이어 마커를 P1로 정한다. 시작 월급은 지급하지 않는다.
  6. X가 먼저 이동하고 P1→P2→P3→P4 순으로 첫 라운드를 진행한다. 이후 라운드는 제5.1절의 회전을 적용한다.

초기 가격 P₀는 최초 공급 한 주의 기준가격이고, C₀는 첫 증축 전체에 필요한 금액이다. 이 판에서는 모든 유형에 C₀=2.5T₀를 적용한다. 유형은 첫 공급과 성장 함수의 기본 규모를 정하며, 색깔을 모아 얻는 독점 보너스는 없다.

고정 기준과 누적 상태

  • N₀는 최초 공급 종료 후 실제 발행된 보통주 수다. 미판매 소각분은 포함하지 않는다. 한 번 정하면 이후 증자·지분 매매·묶음 경매로 바꾸지 않는다.
  • 초기 배분 8곳의 N₀는 6이다. 미분양은 N₀=0으로 표시하고, 최초 공급에서 한 주 이상 판매된 직후 실제 수량으로 확정한다.
  • N은 현재 전체 보통주, U는 현재 전체 무의결권 지분, E=N+U는 전체 배당 지분이다.
  • I는 성공한 증축의 목표액만 합한 누적 투자액이다. 최초 주식 판매대금과 초과 납입액은 포함하지 않는다. I는 부동산의 현금 잔고가 아니라 완료한 사업의 기준 투자액 기록이다.
  • x=I/C₀는 최초 증축비 기준 누적 규모다. 모든 부동산은 x=I=0에서 시작한다. 이 판의 발행 규칙에서는 x가 항상 0 이상의 정수다.

실제 통행료 T의 계산

x = I/C₀
T_raw = T₀ × [1 + rb × ln(1+x/b)]
      = T₀ × [1 + 75 × ln(1+x/50)]
통행료 증가분 G = T_raw - T₀
실제 청구 통행료 T = T₀ + floor(G+0.5)

ln은 자연로그, floor는 내림이다. 증가분 G를 1 화폐 단위로 HALF_UP 정수화한다. 실제 통행료 T를 청구·배당·평가에 모두 사용하며, 반올림하지 않은 T_raw를 따로 청구하지 않는다. 이전 방문에서 반올림한 증가분을 누적하지 않고 매번 누적 I 또는 x에서 다시 계산한다. 미분양의 실제 청구 통행료는 이 함수와 관계없이 0이다.

계산 구현은 최소 60자리 유효 십진 정밀도로 자연로그를 계산한다. 반올림 경계 0.5 부근에서 정수화 결과가 불확실하면 정밀도를 높여 확정한다. I와 x를 누적할 때는 정확한 정수 연산을 쓴다. 다음 Python 예시는 제3.1절 수치의 직접 계산법이며 외부 패키지가 필요 없다.

from decimal import Decimal, localcontext, ROUND_HALF_UP

def property_toll(T0, x):
    # T0 is the positive integer initial toll; x is a nonnegative integer.
    assert isinstance(T0, int) and T0 > 0
    assert isinstance(x, int) and x >= 0
    precision = max(60, len(str(T0)) + len(str(x)) + 30)
    while True:
        with localcontext() as ctx:
            ctx.prec = precision
            z = Decimal(T0) * 75 * (1 + Decimal(x) / 50).ln()
            fraction = z - int(z)
            margin = Decimal(1).scaleb(z.adjusted() - precision + 8)
            if abs(fraction - Decimal('0.5')) > margin:
                return T0 + int(z.to_integral_value(rounding=ROUND_HALF_UP))
        precision *= 2

다음 증축 목표액과 발행량

경매 전 발행량 K = N
경매 전 목표액 C = C₀ × N/N₀
성공 시 추가 규모 Δx = N/N₀
성공 후 x_new = x + Δx
성공 후 I_new = I + C = C₀ × x_new

N/N₀는 항상 1, 2, 4, 8, … 중 하나이므로 목표액과 추가 규모도 정확히 계산할 수 있다. N₀=0인 미분양에는 이 계산을 하지 않는다. 상세 의결·입찰·발행은 제10~11절을 따른다.

증축 횟수·투자액·통행료에 상한은 없다. 반올림 전 성장 함수에서는 같은 돈을 추가 투자했을 때 얻는 통행료 증가가 점차 작아진다. 실제 통행료에는 1단위 정수화로 작은 계단이 생길 수 있다. 주당 배당이나 기존 주주의 수익성이 감소해도 증축을 금지하지 않는다. 같은 부동산이 동일한 누적 I에 도달했다면 통행료는 조달 순서와 관계없이 같다.

3.3 경매시장: 주식·부채 묶음 경매

묶음 구성

7번에 도착한 일반 플레이어가 매도자다. 포기하거나, 다음 항목을 자유롭게 조합한 묶음 하나를 공개하고 한 번 경매할 수 있다.

  • 자신이 보유한 어느 부동산의 보통주·무의결권 지분이든 일부 또는 전부. 서로 다른 부동산과 두 종류 지분을 한 묶음에 넣을 수 있다.
  • 자신이 보유한 개인 부채 원금의 일부 또는 전부. 이 원금은 낙찰자가 인수할 지급 의무다.
  • 주식 종류·부동산 수·주식 수·부채 금액에 별도 상한을 두지 않는다. 실제 자기 보유량을 초과할 수는 없다.
  • 주식 수량은 정수, 부채 금액은 0 이상인 정확한 금액이다. 주식만 있거나 부채만 있는 묶음도 허용하지만 둘 다 0인 빈 묶음은 허용하지 않는다.
  • 현금·미래 배당·미래 행동 약속·자유이동권·기금 수령권은 구성품이 아니다.

이 경매는 이미 보유한 자산·부채의 이전이다. 법인 의결과 신주 발행은 하지 않고, 기업의 전체 N·U·E, 고정 N₀, 누적 투자액 I와 규모 x도 바꾸지 않는다. 주식 발행 경매의 v+1장·2v장 제한은 적용하지 않는다.

가격과 입찰

  1. 매도자는 구성과 최저 총가격 L을 공개한다. L은 음수·0·양수인 10의 정수배다. 매도자 현금이 C라면 L은 -C 이상이어야 한다.
  2. 매도자 자신을 제외한 나머지 일반 플레이어 세 명은 각각 묶음 전체에 대한 가격 B 하나를 비공개로 제출하거나 입찰을 포기한다. 은행과 외부 고객은 참여하지 않는다.
  3. B는 음수·0·양수인 10의 정수배이며 B ≥ L이어야 한다. 주식 한 주당 가격이 아니라 묶음 전체의 순수 현금 대금이다.
  4. B > 0이면 입찰자가 B 전액을 현금으로 보유해야 한다. B < 0이면 매도자가 -B 전액을 현금으로 보유해야 한다. 0은 유효한 가격이며 입찰 포기와 구분한다.
  5. 다른 사람의 입찰을 보지 않은 채 모두 확정한 뒤 일괄 공개한다. 수량·최저가·현금·지분·부채를 경매 중에 바꾸지 않는다.
  6. 무자격·중복 제출·가격 단위 위반·최저가 미달·현금 부족 입찰은 해당 입찰자 전체를 무효로 처리한다. 마감 후 다시 제출하지 않는다.
  7. 유효 가격 중 숫자가 가장 큰 가격이 낙찰된다. 예를 들어 -40은 -60보다 높다. 같은 가격이면 제11.3절의 현재 차례 기준 시계방향 순서에서 매도자를 제외하고 앞선 사람이 낙찰된다.
  8. 유효 입찰이 없으면 실패한다. 구성품이나 돈을 옮기지 않으며 같은 방문에서 다시 경매하거나 묶음을 나누어 재시도할 수 없다.

묶음과 최저가를 공개해 경매를 개시하기 전에는 개최를 포기할 수 있다. 개시한 뒤에는 구성 변경이나 철회를 할 수 없으며 실패 또는 성공으로 이번 경매 기회를 사용한다. 유효 낙찰은 매도자가 사후 거절하거나 일부만 이행할 수 없다.

동시 정산

낙찰가격을 B, 이전할 원금을 d라고 할 때 아래를 하나의 거래로 처리한다.

매도자 현금 += B
낙찰자 현금 -= B
매도자 부채 원금 -= d
낙찰자 부채 원금 += d
묶음에 명시된 모든 주식: 매도자에서 낙찰자로 이전
  • 양수 B는 낙찰자가 매도자에게 지급한다. 음수 B는 매도자가 낙찰자에게 -B를 지급한다.
  • 대금은 사람 사이에서만 이동한다. 은행에서 원금을 갚거나 새로 빌리는 거래가 아니므로 전체 개인 부채 합계는 변하지 않는다.
  • 경매 대금은 현금으로 지급한다. 새 대출이나 묶음에 포함된 주식의 재매각을 결제 자금으로 쓸 수 없다.
  • 인수 원금은 낙찰자 자신의 다음 출발점 정산부터 같은 30% 이자 계산에 포함한다. 매도자는 이전한 원금에 대해 이후 이자를 내지 않는다.
  • 각자의 기존 연속 경고는 이전·초기화하지 않는다. 경매에서 부채가 변했다는 이유로 즉시 경고를 주지 않으며, 다음 자기 출발점에서 평소대로 판정한다.
  • 주식과 부채의 소유가 모두 바뀐 뒤 차례를 마친다. 이 방문에서는 일반 지분 거래나 다른 경매를 추가하지 않는다.

3.4 사회보장기금

기금 잔액 F와 현재 납부자 H를 기록한다. 시작값은 F=0, H=없음이다. 납부액은 1회 50이며 선택 납부가 아니다.

일반 플레이어 p가 14번에 도착하면 다음 셋 중 해당하는 하나만 적용한다.

도착 직전 상태처리
F=0p가 50을 납부한다. F=50, H=p로 기록한다.
F>0이고 H=pp가 50을 추가 납부한다. F에 50을 더하고 H는 유지한다.
F>0이고 H가 p가 아님p가 기존 F 전액을 현금으로 받는다. F=0, H=없음으로 초기화한다. 이번 방문에는 납부하지 않는다.
  • 따라서 자기 돈을 자기 재방문으로 돌려받지 못한다. 다른 일반 플레이어가 도착해야 기존 기금을 가져간다.
  • 납부할 현금이 50보다 적으면 있는 현금을 모두 내고 은행이 부족분을 대납한다. 부족분만 그 사람의 개인 부채에 더한다. 기금에는 항상 50 전액이 들어간다.
  • 예를 들어 현금 20이면 현금 20과 은행 대납 30을 기금에 넣고 개인 부채가 30 늘어난다. 경고는 이때 판정하지 않는다.
  • 수령은 소득이며 부채를 자동 상환하지 않는다. 원금 상환은 다음 자기 출발점에서 선택한다.
  • 기금에는 이자·배당이 없으며 개인의 의무 납부 외에 별도 지원금을 더하지 않는다. 기금 잔액은 어떤 개인의 자산이나 청구권으로 평가하지 않는다.
  • 게임 종료 시 남은 기금은 분배하지 않는다.

3.5 자유이동권

일반 플레이어가 21번에 도착하면 다음 자기 차례에만 유효한 자유이동권 하나를 받는다. 다른 사람의 차례가 지나도 사라지지 않는다.

  1. 다음 자기 차례가 시작되면 권리 사용 여부를 먼저 선택한다.
  2. 사용하면 주사위를 굴리지 않고 현재 칸을 제외한 나머지 27칸 중 하나를 목적지로 지정한다.
  3. 현재 위치에서 목적지까지 시계방향으로 이동한다. 이동 거리는 (목적지 - 현재 위치) mod 28이며 1~27칸이다.
  4. 출발점을 지나거나 정확히 도착하면 목적지 처리 전에 제9절의 원금 상환·월급·이자·경고를 정상 정산한다.
  5. 게임이 끝나지 않으면 목적지의 통상 도착 효과를 적용한다. 부동산이면 개인 거래·최초 공급 또는 통행료·배당·경영활동을, 코너이면 해당 코너 효과를 처리한다.
  6. 사용하지 않으면 이번 차례 주사위 두 개로 정상 이동한다.

사용 여부와 관계없이 권리는 그 차례 이동 전에 소모한다. 다음 차례로 미루거나 쌓아 두거나 타인에게 넘길 수 없다. 지나가는 부동산과 7·14·21번의 효과는 적용하지 않는다. 이동 거리에 따른 추가 비용은 없다.

예를 들어 21번에서 7번 경매시장을 지정하면 시계방향으로 14칸을 이동하므로 출발점 정산을 먼저 한다. 두 번째 연속 경고로 끝났다면 경매를 열 수 없다. 0번 출발점을 지정하면 7칸 이동 후 출발점 정산만 한 번 하고 차례를 마친다.

배당 비율 = (v + u) / E

4.2 경영 행동 투표

  • 모든 보통주 주주가 보통주 발행·무의결권 발행·현상 유지 중 하나를 선택합니다.
  • 보통주 1주가 1표이며 보유 표 전부를 한 선택에 행사합니다. 무의결권에는 표가 없습니다.
  • 전원 제출 후 선택과 합계를 공개합니다. 같은 행동의 표를 합산하며 AI도 다른 사람의 제출 내용을 읽지 않습니다.
  • 한 발행안이 전체 보통주의 절반을 넘어야 해당 경매를 엽니다. 정확히 절반·동률·표 분산으로 과반이 없으면 현상을 유지합니다.
  • 최대 주주의 별도 제안권은 없습니다. 현재 차례부터 시계방향으로 제출하며 X 방문에는 선플레이어부터 제출합니다.

4.3 부동산의 현금

부동산에는 운영비·유보금·법인 부채·법인 이자가 없다. 통행료는 전액 배당한다. 법인은 주주에게 대여금을 받거나 은행에서 빌릴 수 없다. 주주가 임의로 배당을 중단하거나 배당 비율을 바꿀 수 없다.

5 차례와 이동

5.1 라운드와 선플레이어

좌석 이름 P1~P4와 앉은 순서는 게임 내내 고정한다. 선플레이어 마커만 완성된 라운드마다 한 좌석씩 시계방향으로 옮긴다. 외부 고객 X는 매 라운드 가장 먼저 한 번 이동하고, 그 뒤 선플레이어부터 시계방향으로 각 사람이 정확히 한 번 차례를 갖는다.

라운드선플레이어실제 진행 순서
1P1X → P1 → P2 → P3 → P4
2P2X → P2 → P3 → P4 → P1
3P3X → P3 → P4 → P1 → P2
4P4X → P4 → P1 → P2 → P3
5P11라운드와 같은 순서, 이후 네 라운드 주기로 반복

외부 고객 차례의 동가 입찰·경영 투표 제출 순서도 그 라운드의 선플레이어부터 시계방향으로 정한다. 일반 플레이어 차례의 우선순위는 현재 차례인 사람부터다. 현재 라운드의 마지막 사람이 누구인지 기록하고, 그 차례가 정상적으로 끝난 뒤에만 라운드 번호와 마커를 옮긴다.

라운드 마커는 말의 보드 위치와 별개다. 마커 이동은 주사위 이동·월급·이자·배당을 발생시키지 않는다. 누구든 두 번째 연속 경고를 받으면 라운드 도중에도 즉시 전체 게임을 끝내며, 남은 사람의 차례를 채우지 않는다.

  • 기본적으로 매 차례 주사위 두 개를 각각 한 번 굴리고 합만큼 이동한다. 자유이동권을 쓰는 일반 플레이어는 제3.5절대로 목적지를 지정한다.
  • 더블 추가 차례는 없다.
  • 지나간 부동산에는 통행료를 내지 않는다.
  • 7·14·21번 도착 효과는 제3.2~3.5절대로 처리한다. 지나갈 때는 적용하지 않는다.
  • 0번 출발점을 지나거나 정확히 도착하면 일반 플레이어만 제9절을 처리한다.
  • 외부 고객은 출발점에서 월급·이자·부채·경고를 처리하지 않는다.

5.2 일반 플레이어 차례

  1. 자유이동권이 있으면 사용 여부와, 사용할 경우 목적지를 유효하게 확정한 뒤 권리를 소모한다. 사용하지 않거나 권리가 없으면 주사위를 굴린다.
  2. 시계방향 이동 경로에 출발점 통과 또는 정확한 도착이 있으면 도착 칸 처리 전에 제9절의 출발점 정산을 한다.
  3. 정산에서 게임이 종료되지 않았다면 도착 칸을 확정한다.
  4. 0번이면 정산을 중복하지 않고 차례를 마친다. 7·14·21번이면 해당 특수 코너를 처리하고 차례를 마친다.
  5. 부동산이면 현재 플레이어가 제6절의 개인 거래를 진행하고 거래 종료를 선언한다.
  6. 도착한 부동산을 처리한다.
    • 미분양이면 제7절의 최초 공급을 진행하고 차례를 마친다.
    • 소유 지분이 있으면 제8절의 통행료와 배당을 처리한다.
  7. 해당 부동산에서 제10절의 경영활동을 최대 한 번 진행한다.
  8. 다음 말로 차례를 넘긴다.

출발점 정산으로 게임이 끝났다면 개인 거래·도착 칸·통행료·배당·경영활동·특수 코너 효과를 추가로 진행하지 않는다.

5.3 외부 고객 차례

  1. 주사위를 굴리고 이동한다.
  2. 개인 거래와 출발점 정산 없이 도착 칸을 확인한다.
  3. 0·7·14·21번 코너이면 특수 효과 없이 차례를 마친다.
  4. 미분양 부동산이면 통행료를 내지 않고 차례를 마친다. 우선 매수·최초 공급 경매·경영활동을 시작하지 않으며, 지분과 분양 상태도 바꾸지 않는다.
  5. 분양된 부동산이면 은행에서 통행료 전액을 지급하고 배당한다.
  6. 해당 부동산에서 경영활동을 최대 한 번 진행한다.
  7. 다음 말로 차례를 넘긴다.

외부 고객은 입찰·우선 매수·지분 매매·안건 제안·투표를 하지 않는다. 외부 고객 방문의 경영 결정은 인간 주주들이 한다.

6 개인 지분 거래

  • 거래는 일반 플레이어가 부동산에 도착한 뒤, 통행료 지급 또는 최초 공급 전에만 한다. 코너에 도착한 차례에는 개인 거래 창을 열지 않는다.
  • 현재 플레이어가 반드시 거래 당사자여야 한다. 다른 사람끼리만 별도 거래할 수 없다.
  • 현재 플레이어는 모든 부동산의 보통주와 무의결권 지분을 사고팔 수 있다. 도착한 부동산에만 한정하지 않는다.
  • 상대방이 동의해야 한다. 은행과 외부 고객은 거래 상대방이 아니다.
  • 한 거래는 한 부동산의 한 종류 지분에 대해 수량과 총대금을 정한다.
  • 수량은 양의 정수, 대금은 0 이상의 정확한 금액으로 정한다. 10단위 제한은 기존 지분 거래에는 적용하지 않는다.
  • 매도자는 해당 수량을 보유하고, 매수자는 대금 전액을 현금으로 보유해야 한다.
  • 대금과 지분은 동시에 이전한다. 이 일반 거래 창에서는 외상, 부채 이전, 자동 대납, 미래 조건부 이행을 허용하지 않는다. 부채 이전은 제3.3절의 경매시장 묶음 경매에서만 가능하다.
  • 무의결권 지분의 재판매 상대방은 보통주 미보유자를 포함한 모든 일반 플레이어다. 발행 경매의 자격 제한과 구분한다.
  • 거래 횟수 제한은 없다. 현재 플레이어가 거래 종료를 선언하면 다음 단계로 넘어간다.
  • 거래가 끝난 뒤에는 배당·경영활동·입찰 중에 추가 지분 거래를 끼워 넣을 수 없다.
  • 통행료를 위해 현금을 남겨 둘 의무는 없다. 거래 후 현금이 부족하면 제8절의 대납을 적용한다.

거래로 도착 부동산의 지분이 바뀌면 그 변경 후 지분으로 이번 통행료 배당과 이후 의결·경매 자격을 계산한다.

7 미분양 부동산 최초 공급

미분양은 보통주 N=0인 상태다. 통행료는 0이다. 이 절의 최초 공급은 일반 플레이어 P1~P4가 방문했을 때만 진행한다. 외부 고객 X가 방문하면 그대로 차례를 마친다. 초기 배분된 8곳은 이미 분양된 상태이므로 이 절을 적용하지 않는다.

7.1 우선 매수

  • 일반 플레이어가 방문했다면 그 사람만 해당 유형의 초기 가격으로 보통주 1주를 살 수 있다.
  • 우선 매수는 선택이다. 현금이 부족하면 살 수 없고, 자동 대납도 없다.
  • 외부 고객 방문에서는 최초 공급 절차 자체를 진행하지 않는다.
  • 우선 매수 시 대금은 은행에 지급하고 즉시 보통주 1주를 받는다.

7.2 최초 경매

  1. 전체 최초 물량은 보통주 5주다.
  2. 우선 매수했다면 잔여 4주, 그렇지 않으면 5주를 경매한다.
  3. P1~P4에게 각각 최대 2장의 입찰 기회를 준다. 우선 매수자도 최대 2장이다.
  4. 제11절의 공통 경매 절차를 적용하되, 입찰가는 해당 유형의 초기 가격 이상이어야 한다.
  5. 유효 표를 높은 가격순으로 잔여 물량까지 선정한다.
  6. 최초 경매에는 목표 총액 조건이 없다. 유효 표 수가 물량보다 적어도 선정된 표는 모두 낙찰된다.
  7. 낙찰자는 자신이 쓴 가격을 은행에 내고 표당 보통주 1주를 받는다.
  8. 미판매 주식은 소각한다. 발행 수량과 권리는 실제 판매된 주식만으로 계산한다.

한 주라도 판매되면 분양된 부동산이 된다. 우선 매수와 경매에서 실제 판매된 총수를 N₀로 한 번 확정하고 I=x=0으로 기록한다. 모두 거절해 0주가 판매됐다면 미분양으로 남기고 N₀=0을 유지하며, 다음 일반 플레이어 방문에서 다시 5주를 대상으로 최초 공급을 진행한다. 그사이에 외부 고객이 방문해도 재시도하지 않는다.

최초 공급은 해당 방문의 경영활동을 모두 사용한다. 같은 방문에서 통행료를 소급해서 받거나 즉시 증축하지 않는다.

8 통행료와 전액 배당

도착 시점에 부동산이 분양돼 있으면 현재 누적 투자액에서 제3.1절대로 계산한 실제 통행료 T를 낸다.

8.1 일반 플레이어의 지급

지급 직전 현금을 C라고 할 때:

자기 현금 지급 = min(C, T)
은행 대납 = max(0, T - C)
지급 후 현금 = max(0, C - T)
새 부채 원금 = 기존 부채 원금 + 은행 대납

부동산에는 현금 지급분과 대납분을 합친 T 전액이 들어온다. 지급 중 경고를 판정하지 않는다.

8.2 외부 고객의 지급

은행이 T 전액을 지급한다. 고객에게 부채나 경고는 생기지 않는다.

8.3 즉시 배당

통행료 지급 직후, 현재 각 주주에게 다음 금액을 동시에 지급한다.

개인 배당 = T × (개인 보통주 + 개인 무의결권 지분) / E
  • 방문자가 주주라면 그 사람도 배당받는다.
  • 자기 몫을 통행료에서 먼저 빼지 않는다. 전액 지급·대납 후 배당 순서를 지킨다.
  • 예를 들어 현금 0인 방문자가 부동산의 지분 전부를 보유했다면, T만큼 부채가 생긴 뒤 배당 T를 현금으로 받는다.
  • 배당받은 돈은 직후 경매에 사용할 수 있다.
  • 이번 방문의 배당에는 나중에 발행할 신주를 포함하지 않는다.
  • 전액 배당 후 부동산에 현금을 남기지 않는다.

9 출발점 정산과 경고

이 절은 일반 플레이어가 한 바퀴를 완성할 때 한 번 처리한다.

9.1 원금 선상환

  1. 현재 현금 C와 부채 원금 D를 확인한다.
  2. 해당 플레이어가 상환액 R을 선택한다. 선택 범위는 0 이상 min(C,D) 이하이다.
  3. 현금에서 R을 은행에 지급하고 부채 원금을 R만큼 줄인다.

이번 월급을 미리 사용해 원금을 상환할 수는 없다. 이 단계에서 지분을 팔 수도 없다. 이전 차례의 개인 거래와 배당으로 마련해 둔 현금을 쓴다.

9.2 이자와 월급

상환 후 원금 D에 대해 J=0.30×D를 계산한다.

월급 W = 100
현금 증가 = max(0, W - J)
부채 원금 증가 = max(0, J - W)
  • 이자 전체를 부채에 더하는 것이 아니라 월급으로 못 갚은 차액만 더한다.
  • 이자를 냈다는 이유만으로 원금이 줄지는 않는다.
  • 이자 차액으로 늘어난 원금의 추가 이자는 다음 출발점에서 계산한다.
  • 월급 지급 후 이번 차례에 추가 원금 상환 창을 열지 않는다.
  • 은행에 대한 원금 상환은 이 출발점 절차에서만 할 수 있다. 제3.3절의 채무 인수는 다른 사람에게 원금을 이전하는 것이며 은행에 갚는 상환과 구분한다.

9.3 경고 판정

이번 정산에서 계산한 J를 기준으로 판정한다.

조건경고 처리
J < 100경고 횟수를 0으로 초기화
J ≥ 100연속 경고 횟수에 1 추가

이자가 정확히 100이면 월급은 0, 추가 부채는 0이지만 경고는 발생한다.

연속 경고가 2가 되면 즉시 게임을 종료하고 제12절을 적용한다. 경고 1회만으로 지분을 압류하거나 강제 매각하지 않는다. 개인의 순자산이 음수라는 이유만으로 탈락시키지도 않는다.

10 방문 후 경영활동

10.1 주주 전원의 행동 선택

최초 공급 방문에서는 경영 투표를 하지 않습니다. 분양된 부동산에서는 통행료·배당 처리 후 모든 보통주 주주가 보통주 발행·무의결권 발행·현상 유지 중 하나를 선택합니다. 발행량·모집 목표·증축 효과는 기존 공식으로 정해집니다.

10.2 합산과 활동 종료

  • 발행안이 전체 보통주의 과반을 얻으면 해당 종류의 발행 경매를 한 번 엽니다.
  • 과반 발행안이 없으면 현상 유지로 마칩니다. 재투표·별도 제안 단계는 없습니다.
  • 4·3·3주 구조에서도 두 3주 주주가 같은 행동을 선택하면 6/10표의 과반 연합을 만들 수 있습니다.
  • 경매 성공·실패에 관계없이 이번 방문의 경영활동은 한 번입니다.
  • 새 통행료·배당 비율은 다음 방문부터 적용하며, 이번 방문의 배당은 다시 계산하지 않습니다.

11 주식 발행 공통 경매 절차

이 절은 제7절의 최초 공급과 제10절의 증축 신주 발행에 적용한다. 제3.3절의 묶음 경매는 묶음 전체당 1인 1표, 음수 가격 허용 등 별도 절차를 따른다.

11.1 제출

  • 입찰표 한 장은 신주 한 주에 대한 가격이다.
  • 최대 기회보다 적게 내거나 한 장도 내지 않을 수 있다.
  • 모든 사람이 입찰을 확정한 뒤 한꺼번에 공개한다. 다른 사람의 입찰을 본 후 자신의 입찰을 변경할 수 없다.
  • 각자는 현재 보유 현금 전부를 입찰에 사용할 수 있다. 의무적인 개인 현금 유보는 없다.
  • 한 사람의 제출 표 금액 합계가 현재 현금 이하여야 한다. 낙찰 가능성이 낮다는 이유로 한도를 초과할 수 없다.
  • 입찰 중 예상 배당·향후 월급·향후 매각대금·새 부채를 자금으로 인정하지 않는다.

11.2 유효성

제출 전에 최대 수량과 가격의 10 단위를 검사하며, 잘못 입력하면 반려하고 수정할 수 있습니다. 제출 후에는 아래 규칙에 따라 유효성을 판정합니다.

  1. 입찰 수량이 한도를 초과하면 제출 전에 반려합니다. 가격×수량과 개별 가격 목록을 모두 합산하며, 수량을 고쳐 차례 소비 없이 다시 제출할 수 있습니다. 자격 없는 제출은 무효입니다.
  2. 가격이 양의 정수이자 10의 배수가 아닌 표는 무효다.
  3. 최초 공급에서는 초기 가격보다 낮은 표도 무효다. 이후 증축 발행에는 초기 가격 하한을 적용하지 않는다.
  4. 남은 유효 표의 금액 합계가 그 사람의 현금을 초과하면 그 사람의 남은 표 전체가 무효다.
  5. 무효 표를 제거한 뒤 배정한다. 마감 후 다시 제출할 수 없다.

11.3 가격과 동가 우선순위

  • 높은 가격의 표를 낮은 가격의 표보다 먼저 배정한다.
  • 서로 다른 가격 사이에는 시계방향 우선권을 적용하지 않는다.
  • 같은 가격 안에서는 사람별로 한 장씩 돌아가며 배정한다.
현재 차례동가 배정 시작 순서
X현재 라운드의 선플레이어부터 시계방향
P1P1 → P2 → P3 → P4
P2P2 → P3 → P4 → P1
P3P3 → P4 → P1 → P2
P4P4 → P1 → P2 → P3

각 가격 그룹마다 위 순서의 첫 사람부터 시작한다. 해당 가격의 표가 없는 사람은 건너뛴다. 한 바퀴 후에도 물량과 동가 표가 남으면 다시 같은 순서로 한 장씩 배정한다.

예를 들어 P2 차례에 P1이 50짜리 3장, P2가 50짜리 1장, P3이 50짜리 2장을 제출했다면 동가 배정 순서는 P2, P3, P1, P3, P1, P1이다.

11.4 납입

낙찰자는 자신이 적은 가격을 낸다. 마지막 낙찰가로 통일하지 않는다. 낙찰되지 않은 표의 돈은 내지 않는다. 입찰 한도 검사를 통과했으므로 정상 낙찰 후 현금 부족이 발생하지 않아야 한다.

12 종료와 순위 평가

12.1 종료 스냅샷

두 번째 연속 경고를 받은 출발점 정산 직후 상태를 고정한다. 진행 중인 이동의 도착 칸 효과는 적용하지 않는다. 추가 거래·배당·증자·월급을 지급하지 않는다.

그전에 완료한 모든 현금 이전과 지분 발행은 유지한다. 탈락자의 지분을 은행이나 다른 사람에게 이전하지 않는다.

12.2 부동산과 지분 평가

부동산 j의 현재 통행료를 T_j라고 할 때 전체 평가액은 아래 고정 기준으로 계산한다. 자유이동으로 실제 방문 빈도가 달라지더라도 평가 계수 20/7을 바꾸지 않는다.

V_j = T_j × (일반 플레이어 4 + 외부 고객 1) / 기준 주사위 평균합 7 × 평가배수 4
    = T_j × 20 / 7

플레이어 p의 해당 부동산 지분 평가액:

V_j × (p의 보통주 + p의 무의결권 지분) / E_j
  • 두 종류의 지분은 동일한 한 주당 평가액을 갖는다.
  • 미분양 부동산은 누구의 자산에도 포함하지 않는다.
  • 최근 방문 실적, 거래가격, 경매 납입액은 평가식에 사용하지 않는다.
  • 의결권에 별도 보너스를 붙이지 않는다.
  • 증축비나 초과 납입액을 평가액에 추가하지 않는다.
  • 사회보장기금 잔액과 미사용 자유이동권은 개인 순자산에 포함하지 않는다.

12.3 개인 순자산

순자산 = 현재 현금 + 모든 부동산의 보유 지분 평가액 합계 - 현재 부채 원금

탈락자는 무조건 4위다. 나머지 셋을 정확한 순자산으로 비교한다. 표시용 반올림 값이 같더라도 원값이 다르면 높은 쪽이 앞선다. 원값까지 같으면 공동 순위를 적용한다.

13.2 플레이어에게 받을 선택

  • 개인 거래: 상대방, 부동산, 지분 종류, 수량, 총대금, 양측 동의, 거래 종료 여부.
  • 원금 상환: 이번 상환액 R.
  • 일반 플레이어의 미분양 방문: 우선 매수 여부. 외부 고객의 미분양 방문에는 선택 입력을 받지 않는다.
  • 경영활동: 각 주주의 보통주 발행·무의결권 발행·현상 유지 선택과 표 합계.
  • 주식 발행 경매: 한 사람의 입찰표 가격 목록. 빈 목록은 입찰 포기다.
  • 묶음 경매: 개최 여부, 주식 구성, 이전 부채 d, 최저가 L, 나머지 사람별 가격 B 또는 입찰 포기. 가격 0과 입찰 포기를 구분한다.
  • 자유이동권: 다음 차례 사용 여부와 사용할 때의 목적지.
  • 기금: 납부 또는 수령을 상태에 따라 자동 처리하므로 별도 전략 입력을 받지 않는다.

입력받지 않은 전략적 선택을 진행자가 임의로 확정하지 않는다. AI 플레이어는 이 규칙 안에서 자체 전략으로 결정할 수 있다. 주사위는 각 면이 동일 확률이 되도록 굴린다.

13.3 처리 원칙

  • 모든 행동은 권한·소유 수량·현금을 먼저 검사한다.
  • 잘못된 개인 거래·상환 요청·묶음 구성·최저가·목적지는 상태를 바꾸지 않고 다시 선택하게 한다. 발행 경매의 무효 표는 제11.2절, 묶음 경매의 무효 입찰은 제3.3절대로 처리한다.
  • 발행 경매 납입·지분 발행·x 갱신·통행료 재계산은 성공이 확정된 뒤 한꺼번에 적용한다. 묶음 경매도 현금·주식·부채 이전을 한꺼번에 적용한다.
  • 묶음 경매 전후 전체 개인 현금 합계와 전체 개인 부채 합계는 각각 같아야 한다.
  • 기금은 F=0이면 H=없음, F>0이면 실제 납부자인 일반 플레이어 한 명을 기록해야 한다.
  • 부채가 늘었다는 사실만으로 즉시 경고를 주지 않는다. 경고는 출발점에서만 판정한다.
  • 새 신주에 이번 방문의 과거 배당을 소급하지 않는다.
  • 최초 공급 미판매분 소각 또는 이후 신주 발행 뒤에는 실제 N·U·E를 다시 계산한다. 최초 확정된 N₀는 바꾸지 않는다. 분양된 부동산은 E=N₀(1+x), I=C₀x를 검산한다.
  • 통행료 함수는 제3.1절의 정수화 결과를 사용한다. 표시용 소수 반올림과 이 규칙상 정수화를 구분한다.
  • 게임이 종료되면 즉시 순위 평가로 넘어가며 다른 행동을 받지 않는다.

14 정산 예시

아래에서 N₀=5인 예시는 미분양 부동산의 최초 공급으로 5주가 판매된 경우다. 초기 배분 수량과 구별한다.

예시 A 통행료 부족

P1의 현금이 30이고 도착 부동산의 통행료가 80이라면 현금 30을 쓰고 은행이 50을 대납한다. P1의 부채 원금이 50 늘고, 부동산 주주들은 합계 80을 배당받는다. P1도 해당 지분이 있다면 그 뒤 자신의 몫을 받는다.

예시 B 원금 상환으로 경고 방지

P1이 경고 1회, 부채 400, 현금 100 상태에서 출발점을 지난다. 원금 100을 먼저 상환하면 잔여 원금 300, 이자 90이 된다. 월급 실수령은 10, 경고는 0으로 초기화된다.

같은 상태에서 상환하지 않으면 이자 120, 실수령 0, 부채 420이 되고 두 번째 연속 경고로 즉시 게임이 끝난다.

예시 C 소각 후 증축

B형 최초 5주 중 3주만 팔렸다면 N₀=N=3이다. 다음 증축의 발행량은 3주, 첫 목표액은 C₀×3/3=200이다. 보통주 2주 보유자는 보통주 증자에 3장, 무의결권 발행에 4장까지 입찰할 수 있다.

보통주 발행에 성공하면 N=6, x=1, I=200이고 다음 목표액은 400이다. 무의결권 발행에 성공했다면 N=3, U=3, x=1, I=200이고 다음 목표액은 200 그대로다. 두 방식 모두 이번 확장 직후의 실제 통행료는 199다.

예시 D 초과 조달

B형에서 N₀=N=5, x=0일 때 목표액은 200이다. 상위 다섯 가격이 70, 60, 50, 40, 30이면 총 250을 납입하고 발행한다. I는 200, x는 1이 되며 실제 통행료는 199다. 초과 50은 누구에게도 돌아오지 않으며 I에도 더하지 않는다.

예시 E 종료 평가

B형 첫 무의결권 발행 후 통행료 199, 보통주 5주, 무의결권 지분 5주라면 전체 가치는 3980/7이다. 배당 지분 3주 보유자의 몫은 1194/7이다. 그 사람이 현금 200, 부채 100을 보유하고 다른 지분이 없다면 순자산은 1894/7, 약 270.57이다.

예시 F 공동경영으로 시작한 부동산 방문

A형 추첨에서 P1·P2가 뽑혔다면 1번 부동산의 보통주는 P1·P2·P3·P4 순으로 2·2·1·1주다. 외부 고객이 처음 그곳에 도착하면 통행료 60을 지급하고 각각 20·20·10·10을 배당한다. 최초 공급 경매는 하지 않는다.

P1 혼자의 2표와 P1·P3의 합계 3표는 가결할 수 없다. P1·P2의 합계 4표는 전체 6표의 과반이어서 가결할 수 있다. 이때 첫 증축의 발행량은 6주, 목표액은 150이다. 보통주 발행의 개인별 입찰 한도는 3·3·2·2장, 무의결권 발행은 4·4·2·2장이다. 성공하면 이번 방문의 배당을 다시 계산하지 않고 다음 방문부터 새 통행료를 적용한다.

예시 G 외부 고객의 미분양 방문

2번 A형은 시작 시 미분양이다. 외부 고객이 도착해도 통행료·배당·경매 없이 차례를 마치며 보통주는 계속 0주다. 이후 P2가 처음 도착하면 P2의 개인 거래 창을 먼저 연 뒤, 우선 매수와 최초 공급 경매를 진행한다.

예시 H 음수 가격의 묶음 경매

매도자 P1은 현금 70·부채 400 상태에서 자기 주식 묶음과 원금 150을 내놓고 최저가 -70을 정한다. P2가 -40, P3가 -60을 제출하고 P4가 포기하면 -40이 더 높으므로 P2가 낙찰된다.

P1은 P2에게 현금 40을 지급하고 주식과 부채 150을 넘긴다. P1의 현금은 30, 부채는 250이 된다. P2가 경매 전 현금 50·부채 100이었다면 경매 후 현금 90·부채 250과 주식 묶음을 보유한다. 둘의 현금 합계 120과 부채 합계 500은 각각 그대로다. 누구의 경고도 이 경매만으로 바뀌지 않는다.

예시 I 기금 납부와 수령

기금이 비어 있을 때 현금 20·부채 0인 P1이 도착하면 현금 20과 은행 대납 30으로 50을 납부한다. P1의 현금은 0, 부채는 30이 되고 F=50, H=P1이다.

다음에 P2가 도착하면 P2가 50을 전액 받고 기금은 0이 된다. P2는 그 방문에 다시 50을 납부하지 않는다. P2보다 먼저 P1이 재방문했다면 P1이 50을 더 납부해 F=100, H=P1이 된다.

예시 J 다음 차례 목적지 선택

P1이 21번에 도착하면 그 차례에는 이동권만 얻는다. 다음 P1 차례에 14번을 지정하면 시계방향 21칸을 이동한다. 그 경로에서 출발점을 지나므로 원금·이자·월급·경고를 먼저 정산하고, 게임이 끝나지 않았다면 사회보장기금을 처리한다. 14번 수령액을 앞선 출발점 상환에 미리 사용할 수는 없다.

예시 K 같은 투자액의 서로 다른 조달 경로

C형 N₀=5에서 보통주로만 두 번 발행하면 N=20, U=0, x=3, I=750이 된다. 무의결권으로만 세 번 발행하면 N=5, U=15, x=3, I=750이 된다. 둘 다 E=20, 실제 통행료 537, 방문당 주당 배당 26.85다. 의결권 구조와 필요한 방문 횟수는 다르다.

예시 L 수익성이 낮아진 뒤에도 가능한 확장

C형 N₀=5에서 보통주로만 세 번 발행하면 N=40, x=7, I=1,750, 실제 통행료 1,083, 주당 배당 27.075다. 한 번 더 성공하면 N=80, x=15, I=3,750, 실제 통행료 2,068, 주당 배당 25.85다. 주당 배당은 감소하지만 그 이유만으로 네 번째 발행을 금지하지 않는다. 경매의 의결·현금·물량·목표액 조건은 그대로 충족해야 한다.

15 확정 운영 세칙과 적용 범위

다음 사항은 본문과 함께 적용하는 확정 규칙이다. 진행자는 추가 설계 결정을 요구하지 않고 이 문서대로 실행한다.

  • 각 변의 부동산을 A·B·C·D형 중 한 유형으로 통일해 각각 6곳 배치함. 초기 분양은 각 유형 2곳, 총 8곳의 보통주 48주이며, 부동산별 6주를 2·2·1·1로 나누고 같은 유형의 두 번째 부동산은 각자 3주가 되도록 보완 배분함. 각자 총 12주·같은 초기 배당 가치이며 단독 과반 없이 공동경영으로 시작함. 라운드마다 선플레이어와 외부 고객 차례의 우선권을 회전함.
  • 증축 횟수·사업 규모 상한 없이 제3.1절의 누적 투자액 함수를 적용함. r=1.5, b=50, 통행료 증가분의 1단위 HALF_UP 정수화까지 이 판의 규칙으로 정함.
  • N₀는 최초 공급 후 고정, 이번 발행량은 현재 N, 목표액은 C₀×N/N₀임. 성공한 증축의 목표액만 I에 합산하고 초과 납입액은 소멸함.
  • 미분양 통행료는 0이고, 최초 공급은 일반 플레이어 방문 때만 진행함. 외부 고객은 미분양 부동산에서 아무 절차 없이 통과함.
  • 최초 공급에서 0주 판매 시 다음 일반 플레이어 방문에 재시도함.
  • 최초 공급과 부결·실패한 경영활동도 방문당 기회 소비.
  • 모든 보통주 주주가 세 경영 행동에 투표하며 같은 발행안의 표를 합산한다. 최대 주주의 별도 제안권은 없다.
  • 기존 지분 매매는 현재 플레이어가 당사자인 즉시 현금 거래만 허용하고, 무의결권 지분의 재판매 상대는 제한하지 않음.
  • 일반 지분 거래 창은 부동산 도착 때만 열며, 코너 방문에서는 열지 않음. 7번에서는 주식과 개인 부채로 구성한 묶음 하나의 별도 경매를 허용함.
  • 묶음의 부채는 낙찰자가 인수하고, 낙찰가격은 음수도 가능하며, 기존 경고는 이전하지 않음.
  • 14번의 의무 납부액은 50이며 현금 부족분은 개인 부채로 대납함. 타 납부자의 기금을 수령하는 방문에는 재납부하지 않음.
  • 21번에서 얻은 이동권은 다음 자기 차례에만 사용할 수 있고, 지정 이동도 시계방향으로 진행하며 출발점 정산을 적용함.
  • 외부 고객에게 특수 코너 효과를 적용하지 않음.
  • 경매 동안 거래 금지, 제출 목록의 현금 한도 검사, 무효 표 처리 순서.
  • 자기 몫을 상계하지 않고 통행료 전액 지급 후 즉시 배당.
  • 월급 전 기존 현금으로 원금 상환, 월급 후 추가 상환 창 없음.
  • 금액은 정확한 분수 계산 기준, 최종 동점은 공동 순위.
  • 이 문서의 특수 코너 외 별도 이벤트, 더블 추가 차례, 법인 부채, 강제 지분 매각, 턴 제한 종료는 적용하지 않음.

정상 종료 조건이 발생하지 않으면 계속 진행한다. 컴퓨터나 진행 환경의 관찰 한도 때문에 중단한다면 진행 중인 상태로 보존하며, 이를 게임 종료나 승패 확정으로 처리하지 않는다.

보드와 플레이어 카드 읽기

  • 칸을 누르면 아래의 부동산 살펴보기에서 통행료·지분 명부·발행 조건을 확인합니다. 코너도 같은 영역에 설명이 나옵니다.
  • 원그래프는 플레이어별 소유 비율입니다. 배당 지분과 의결권을 전환할 수 있습니다.
  • 말은 칸 왼쪽 아래부터 도착한 순서로 표시됩니다. X는 외부 고객입니다.
  • 카드의 보유 지분을 누르면 24개 자산의 보유 현황을 한눈에 봅니다. 플레이어 이름을 누르면 그 사람의 재무 화면으로 갑니다.

거래·의결·입찰 입력하기

  • 개인 거래: 상대·자산·지분 종류·수량·총대금을 입력합니다. 거래가 끝나면 도착 처리를 계속하세요.
  • 의결: 모든 보통주 주주가 보통주 발행·무의결권 발행·현상 유지에 직접 투표합니다. 같은 발행안을 고른 주주들의 표 합계가 전체 보통주의 절반을 넘어야 경매로 이어집니다.
  • 신주 입찰: 50, 40, 30처럼 주당 가격을 나열합니다. 50×3은 50짜리 표 3장입니다. 빈칸은 포기이며, 제출 전 수량과 현금을 확인하세요.
  • 묶음 입찰: 묶음 전체의 가격을 입력합니다. 0도 입찰이며 빈칸인 포기와 다릅니다. 음수 가격은 매도자가 낙찰자에게 지급합니다.

  • 누적 수입·지출은 실제 현금 흐름입니다. 초기 현금과 은행 대납은 수입에서 제외합니다. 상세 정의는 지표 설명에 표시됩니다.

AI와 시드는 어떻게 동작하나요?

새 게임에서 전략가·확장가·가치투자자·수비가를 자리마다 고르거나 무작위로 편성합니다. 전략가는 상대의 이득, 확장가는 보통주 성장과 의결권, 가치투자자는 가격 대비 수익과 무의결권, 수비가는 현금과 부채 위험을 우선합니다. 성향은 난이도 순서가 아닙니다. 새 AI는 입찰가를 비교하고 불리한 발행보다 현상 유지를 선택하며, 현금과 부채가 위험하면 다른 AI에게 지분 매각을 제안합니다. 상대 AI도 가격과 지급 여력을 확인해야 거래가 성립합니다. 미래 주사위와 비공개 입찰은 읽지 않습니다. 기존 AI와 실험용 v1도 비교용으로 선택할 수 있으며, 이전 저장은 당시 전략을 그대로 유지합니다. 무작위 편성은 가능한 한 중복 없이 배정하고, 같은 시드와 같은 선택으로 재현됩니다. 배정용 난수는 게임 주사위와 분리됩니다. 저장·복원·되돌리기는 배정된 성향을 유지합니다. 시드가 같아도 플레이 중 선택이 다르면 이후 주사위 사용 순서와 진행이 달라질 수 있습니다.
